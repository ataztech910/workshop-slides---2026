Three — a tool that does the same thing for you.
Four — what arrives: six bugs, found in seconds.
Five — AI: agents that investigate on their own.

Everything runs on your machine. No cloud accounts, no API keys. If you have a model key, good — if not, there is a mock model, and every mission works with it.
